# Kollab brand package

This package was prepared from six visual files supplied by the user.

## Source quality and verification

- The original JPG logo is preserved, while the render manifest uses a transparent PNG derivative.
- Brand and product statements were inferred only from visible content in the supplied posts.
- Any statement marked `Needs verification` must be confirmed by Kollab before publication.
- Historical names, metrics, testimonials, and campaign counts in reference posters must not be
  reused as current facts without written confirmation.

## Package layout

- `knowledge/`: text sources ingested into RAG.
- `assets/logos/`: official logo source supplied by the user.
- `assets/references/`: previous posts used as visual references.
- `assets/products/`: reserved for a clean approved platform UI screenshot or device mockup.
- `assets/lifestyle/`: reserved for approved photography.
- `assets/fonts/`: reserved for licensed brand font files.
- `briefs/campaign-brief.json`: campaign request for a company-overview poster.

## Product visual

The supplied files did not contain a clean product/UI cutout, so `assets/products/` contains a
transparent illustrative creator-platform mockup derived from the reference posts. It avoids
readable customer/campaign data and should be replaced by an authorized current screenshot when
Kollab provides one.
