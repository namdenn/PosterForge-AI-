# Product asset

`kollab-platform-ui.png` is a transparent illustrative platform mockup derived from the supplied
Kollab reference posts. It intentionally contains no readable account, campaign, price, or
performance data and must not be described as an exact screenshot of the live product.

The user should visually approve the illustration before publication. Replace it later with a
clean, current, authorized product screenshot when one becomes available.

Requirements:

- Do not replace it with a complete previous poster.
- Remove or anonymize personal information and unapproved campaign data.
- Prefer a high-resolution PNG with a transparent background or a clean rectangular screenshot.
- Keep it registered as `asset_type: "product"` in `../asset_manifest.json`.
